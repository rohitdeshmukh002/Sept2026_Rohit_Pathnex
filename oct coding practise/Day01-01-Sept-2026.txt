## Ansible task - install nginx on server

```yaml
- name: install nginx on server
  hosts: all
  become: yes

  tasks:
    - name: Install Ngnix
      yum :
        name: nginx
        state: present

    - name: start nginx
      yum:
        name: nginx
        state: start

    - name: enable nginx
      yum:
        name: nginx
        state: enable
