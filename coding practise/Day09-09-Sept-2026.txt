# Day 09 — Templates, Internet Gateway, ConfigMap, CPU Load

## Ansible — Use Jinja2 Template

---
- name: Deploy template for Rohit
  hosts: all
  become: yes

  tasks:
    - name: Copy template file
      template:
        src: rohit.conf.j2
        dest: /etc/rohit.conf

# Artifacts and Archiving

## Jenkins Pipeline — Archive Artifacts
You will learn how to **save build artifacts for future use**.

pipeline {
    agent any
    environment {
        INSTITUTE_NAME = "Rohit"
    }
    stages {
        stage('Checkout') {
            steps {
                git url: 'https://github.com/Rohit/sample-java-app.git'
            }
        }
        stage('Build') {
            steps {
                sh 'mvn clean package'
            }
        }
        stage('Archive') {
            steps {
                archiveArtifacts artifacts: 'target/*.jar', fingerprint: true
            }
        }
    }
}

## GitLab CI — Artifacts
You will learn how to **store artifacts in GitLab CI**.

stages:
  - build

build:
  stage: build
  image: maven:3.8.1-jdk-17
  script:
    - git clone https://github.com/Rohit/sample-java-app.git
    - cd sample-java-app
    - mvn clean package
  artifacts:
    paths:
      - target/*.jar
    expire_in: 1 week
