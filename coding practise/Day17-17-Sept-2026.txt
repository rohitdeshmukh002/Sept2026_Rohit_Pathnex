# Day 17 — Loops, ALB, Namespace, Top Processes

## 🔹 Ansible — Create Multiple Users in Loop

---
- name: Create multiple Rohit users
  hosts: all
  become: yes

  vars:
    users:
      - dev1
      - dev2
      - dev3

  tasks:
    - name: Create users
      user:
        name: "{{ item }}"
        state: present
      loop: "{{ users }}"

## 🔹 Kubernetes — Namespace + Deployment

apiVersion: v1
kind: Namespace
metadata:
  name: rohit-namespace

---
apiVersion: apps/v1
kind: Deployment
metadata:
  name: rohit-deploy
  namespace: rohit-namespace
spec:
  replicas: 2
  selector:
    matchLabels:
      app: rohit
  template:
    metadata:
      labels:
        app: rohit
    spec:
      containers:
        - name: app
          image: nginx

# Deployment Simulation

## 🔹 Jenkins Pipeline — Simulated Deployment
You will learn how to **simulate deployment to different environments**.

pipeline {
    agent any
    parameters {
        choice(name: 'ENVIRONMENT', choices: ['dev', 'staging', 'prod'], description: 'Deployment Environment')
    }
    environment {
        INSTITUTE_NAME = "rohit"
    }
    stages {
        stage('Deploy') {
            steps {
                sh 'echo "Deploying $INSTITUTE_NAME application to $ENVIRONMENT"'
            }
        }
    }
}

## 🔹 GitLab CI — Deployment Simulation
You will learn how to **simulate deployment in GitLab CI using environment variable**.

stages:
  - deploy

variables:
  INSTITUTE_NAME: "Rohit"
  ENVIRONMENT: "staging"

deploy:
  stage: deploy
  image: alpine:latest
  script:
    - echo "Deploying $INSTITUTE_NAME application to $ENVIRONMENT"
