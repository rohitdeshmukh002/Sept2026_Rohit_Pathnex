# Day 19 — Git Deploy, RDS Skeleton, Rolling Strategy, Ping Check

## Ansible — Deploy App Using Git

---
- name: Deploy app from Git for Rohit
  hosts: all
  become: yes

  tasks:
    - name: Install git
      yum:
        name: git
        state: present

    - name: Clone repository
      git:
        repo: "https://github.com/rohitdeshmukh002/cohert.git"
        dest: "/opt/Rohit-app"

## Kubernetes — Deployment Rolling Update (Detailed)

apiVersion: apps/v1
kind: Deployment
metadata:
  name: rohit-rollout
spec:
  replicas: 3
  strategy:
    type: RollingUpdate
    rollingUpdate:
      maxSurge: 2
      maxUnavailable: 1
  selector:
    matchLabels:
      app: rollout
  template:
    metadata:
      labels:
        app: rollout
    spec:
      containers:
        - name: app
          image: nginx


## Shell Script — Check Internet Connectivity

#!/bin/bash

ping -c 2 google.com &> /dev/null

if [ $? -eq 0 ]; then
  echo "Internet is available"
else
  echo "No internet connection"
fi
