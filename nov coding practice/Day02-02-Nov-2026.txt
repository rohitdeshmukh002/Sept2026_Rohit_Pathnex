# Day 02 — Services & Tags

## 🔹 Ansible — Install & Enable Nginx

---
- name: install nginx and start service
  hosts: all
  become: yes

  tasks:
    - name: install nginx
      yum:
        name: nginx
        state: present
    
    - name: start service
      service:
        name: nginx
        state: started
        enabled: yes

# Maven Build
## 🔹 Jenkins Pipeline — Maven Build
You will learn how to **compile, test, and package a Java project** using Maven.

pipeline {
    agent any
    tools {
        maven 'Maven-3.8.1'
        jdk 'JDK-17'
    }
    stages {
        stage('Checkout') {
            steps {
                git url: 'https://github.com/Pathnex/sample-java-app.git'
            }
        }
        stage('Compile') {
            steps {
                sh 'mvn clean compile'
            }
        }
        stage('Test') {
            steps {
                sh 'mvn test'
            }
        }
        stage('Package') {
            steps {
                sh 'mvn package'
            }
        }
    }
}

## 🔹 GitLab CI — Maven Build

stages:
    - build
    - test
    - package

build:
    stage: build
    image: maven: 3.8.1-jdk-17
    script:
        - git clone https://github.com/pathnex/simple-java-app.git
        - cd simple-java-app
        - mvn clean compile

test:
    stage: test
    image: mvn:3.1.1-jdk-17
    script:
        - cd simple-java-app
        - mvn test
        
maven-package:
  stage: package
  image: maven:3.8.1-jdk-17
  script:
    - cd sample-java-app
    - mvn package
