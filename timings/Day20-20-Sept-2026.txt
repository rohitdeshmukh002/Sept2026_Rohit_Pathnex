# Secrets & Credentials

## Jenkins Pipeline — Using Credentials

pipeline {
    agent any

    environment {
        INSTITUTE_NAME = "Rohit"
    }

    stages {
        stage('Checkout') {
            steps {
                git url: 'https://github.com/rohitdeshmukh002/cohert.git'
            }
        }

        stage('Use Secret') {
            steps {
                withCredentials([
                    string(
                        credentialsId: 'ROHIT_API_KEY',
                        variable: 'API_KEY'
                    )
                ]) {
                    sh '''
                        echo "Using API key for $INSTITUTE_NAME"
                        # Use $API_KEY here when required
                    '''
                }
            }
        }
    }
}

## GitLab CI — Using CI/CD Variables
You will learn how to **use GitLab CI variables securely**.

stages:
  - build

variables:
  INSTITUTE_NAME: "Rohit"
  API_KEY: "PLACEHOLDER_SECRET"

build:
  stage: build
  image: alpine:latest
  script:
    - echo "Using secret $API_KEY for $INSTITUTE_NAME"
